## 4. Key Design Decisions

| ID | Decision | Detail |
|---|---|---|
| D01 | Build backend | `setuptools.build_meta` (not `legacy:build` — pip compat issue) |
| D02 | Package layout | `src/` layout — prevents accidental uninstalled imports |
| D03 | Python interpreter | Use miniforge3 Python 3.12; system Python 3.14 blocked by PEP 668 |
| D04 | Tilt convention | θ > 0 = forward lean (+X direction) |
| D05 | Controller interface | `compute(state: dict, dt: float) → float` total torque; simulation splits L/R |
| D06 | State vector | `[x, x_dot, theta, theta_dot]` — 4-state inverted pendulum |
| D07 | Timestep | 240 Hz (dt ≈ 0.004167 s) for physics + controller |

## 7. Controller Configs

### PID (`config/pid_config.yaml`)
```yaml
Kp: 35.0  Ki: 0.5  Kd: 2.5
integral_clamp: 10.0
derivative_filter_alpha: 0.7   # low-pass on derivative
max_torque_total: 10.0
theta_ref: 0.0
```

